# Roadmap

## Done

- Prism-style instance folders (`instance.cfg`) with a library refresh button.
- Windows/Linux database compatibility.
- Threadrinth branding, amber default and accent color picker (including white).
- Five extra themes: Ember, Sand, Orchid, Amethyst and Blossom.
- Signed GitHub releases, in-app updater and automatic Modrinth upstream sync.
- Skin history: skins changed outside the app (for example on minecraft.net) are saved to the skins page automatically.
- Imports instances from the official Modrinth App (version, loader, icon, playtime), and installs imported instances without needing Repair.

## Next

- **Bug reports:** anonymous error reports (skipped imports, failed installs, crashes) with a switch next to Modrinth's telemetry setting. This needs a free place to send reports first, for example Sentry.
- **CurseForge:** browse and install CurseForge mods, modpacks, resource packs and shaders, behind a settings toggle.

## Later

- macOS builds.
- Code-signed Windows installers (no SmartScreen warning).
